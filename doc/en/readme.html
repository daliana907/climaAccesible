Accessible Weather for NVDA

Author: Daliana | Version 1.4 | Compatibility: NVDA 2019.3 or later

Accessible Weather provides quick and accessible weather reports and multi-day forecasts.

Keyboard Shortcuts

ShortcutAction
NVDA + WAnnounce current weather
NVDA + Shift + WAnnounce multi-day forecast
NVDA + Control + WOpen settings dialog

NVDA Tools Menu

You can also access the add-on from NVDA > Tools > ClimaAccesible:

  • Add-on settings: Open configuration dialog.
  • Check add-on conflicts: Verify shortcut compatibility with other add-ons.
  • Documentation: Open this user guide.
